# OOP-Course-Mukhitov

Локальный сайт «ООП — учебная платформа» для нашей учебной группы. Пять разделов: Главная, Теория, Практика, Тестирование и Результаты. На сайте доступны материалы первой недели: теория, лабораторная Avtobys, вопросы с разбором, эталон Python, тесты и рубрика взаимной проверки.

## Запуск

Нужен публичный Node.js 24 LTS с npm. На Windows можно распаковать официальный ZIP Node в удобный каталог и добавить его в PATH текущего терминала. Постоянное изменение системного PATH не требуется. Проверить среду:

```powershell
node --version
npm.cmd --version
npm.cmd ci
npm.cmd run dev
```

Открыть адрес, который показывает Vite, обычно `http://127.0.0.1:5173`. На macOS/Linux используйте `npm` вместо `npm.cmd`. Остановить сервер: Ctrl+C.

```powershell
npm.cmd run build
npm.cmd run preview
```

Сборка создаёт `dist/`; preview открывает её локально, обычно `http://127.0.0.1:4173`.

Проверено на Windows x64: официальный Node.js 24.21.0, npm 11.19.0; чистая установка, dev, build и preview. Системный Node20 для этого проекта не используйте. В переносном варианте сначала задайте `$env:PATH = 'C:\путь\к\node;' + $env:PATH` в текущем PowerShell, затем проверьте версии и выполните команды из каталога проекта.

## Структура и технологии

- `src/main.jsx` — вход React; `src/App.jsx` — пять представлений и обычные ссылки; `src/styles.css` — оформление и адаптивность.
- `index.html`, `vite.config.js` — вход HTML и настройки Vite; `package-lock.json` фиксирует зависимости для `npm ci`.
- React отображает интерфейс, Vite собирает и запускает его, plugin-react поддерживает JSX. TypeScript и дополнительные UI/router библиотеки не нужны текущему каркасу.

Материалы недели хранятся в `materials/week-01/`. `src/StudyMaterial.jsx` отображает их Markdown (заголовки, абзацы, списки, таблицы, код, ссылки) и включает файлы для скачивания в сборку. Текст редактируется в исходных Markdown-файлах без дублирования в JSX. Навигация использует fragments и поддерживает локальные переходы без сервера приложения.

Самопроверка и оценивание выполняются вручную: ответы и баллы на сайте не сохраняются. Python-примеры запускаются отдельно на компьютере (инструкция на главной странице). Сервер, база данных, аккаунты и публикация не добавлены. Ссылки на исходные PDF первой лекции и лабораторной доступны на главной странице; оригиналы сохранены в `.tfw/COURSE-MATERIALS/`.
