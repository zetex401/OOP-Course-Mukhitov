## Запуск сайта

Нужен публичный Node.js24LTS с npm, например официальный ZIP/установщик с [nodejs.org](https://nodejs.org/en/download). Системный Node 20 для этого проекта не подходит. Команды из папки проекта в PowerShell:

```powershell
node --version
npm.cmd --version
npm.cmd ci
npm.cmd run dev
```

Откройте адрес Vite, обычно http://127.0.0.1:5173. Остановка Ctrl+C. Для production:

```powershell
npm.cmd run build
npm.cmd run preview
```

Preview обычно http://127.0.0.1:4173; dist воспроизводим, не хранится в Git. На macOS/Linux используйте npm вместо npm.cmd. На Windows распакованный Node можно добавить в PATH текущего терминала; приватные пути/инструменты агента пользователю не нужны. Поведенческие проверки сайта: `node --test tests/*.test.js`.

## Как дать одногруппнику пройти

Передайте локальную копию исходников этого принятого результата без node_modules/dist/кэшей/.venv и личных данных. Одногруппник выполняет npm ci и dev на своём Node 24. Начало — [маршрут недели](materials/week-01/README.md). Для Python отдельно нужны 3.12+ и pytest; проверка готовности/команды установки указаны в маршруте. Скачиваемый starter создаёт domain-папку; готовые валидаторы даны открыто, переходы состояния/тесты/защиту выполняет студент. Справочный набор можно явно направить на свою domain-папку; запуск эталона не считается проверкой своей модели.

В «Результатах» нажмите «Выделить результат для копирования», затем Ctrl+C (macOS: Cmd+C) и вставьте в свой текстовый файл; сохраните его. Передача файла напарнику — действие пользователя; сайт никому его не отправляет. Для ручной лабораторной есть форма обратной связи. Фактическое взаимное прохождение и официальная отправка преподавателю не заявлены.
