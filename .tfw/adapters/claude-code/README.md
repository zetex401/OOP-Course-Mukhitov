# Адаптер Claude Code

Claude Code находит постоянные инструкции в корневом `CLAUDE.md`, а прежние копии slash-команд —
в `.claude/commands/`. Точные команды manifest, канонические рабочие процессы и роли перечислены
в `../manifest.yaml`; за `/tfw-research` отвечает Researcher.

## Установка или восстановление

Стандартная команда `/tfw-economics` использует `.claude/commands/tfw-economics.md` — копию
канонического рабочего процесса. Только Daily использует явно выбранный краткий механизм обнаружения
в `.claude/skills/`. Перед заменой или удалением прежних необязательных псевдонимов Economics
изучите миграцию ядра; сохраните пользовательские файлы и историю.

1. Копируйте `CLAUDE.md.template`, только если `CLAUDE.md` отсутствует. Иначе синхронизируйте лишь
   управляемый блок `TFW:CLAUDE`; существующий файл без такой отметки оставьте без изменений и сообщите о нём.
2. Сохраните идентичность проекта, стандарты кода и весь текст за пределами управляемого блока.
3. Копируйте каждый рабочий процесс из manifest в `.claude/commands/tfw-{command}.md`, включая
   `.tfw/workflows/research/base.md` для `/tfw-research`.
4. Проверьте точный набор файлов команд из manifest, совпадение исходных байтов, канонические роли,
   разрешение путей и идемпотентность. Отсутствующие или лишние команды TFW считаются ошибкой.

Копии команд — артефакты обнаружения команд конкретной платформой, а не самостоятельные источники
алгоритмов. Каждая начинается с содержимого канонического рабочего процесса; постоянный блок
направляет дальнейшее чтение по его Read Contract.

Economics по умолчанию устанавливается и обновляется из manifest с выбранными адаптерами и
использует `.tfw/workflows/economics.md`. Сохраняются четыре формальные роли; анализ соблюдает
активный Role Lock. Подключение Daily — отдельное решение. Общий кэш публичных тарифов и копии
ценовых предложений, использованных в поручениях, описаны в общей инструкции Economics; перед
записью в старые необязательные или пользовательские точки входа изучите `migrations/economics-core.md`.
