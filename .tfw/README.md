# North Star проекта OOP-Course-Mukhitov

## Назначение

Простой локальный сайт помогает владельцу и его одногруппникам изучать основы объектно-ориентированного программирования. Текущий этап — понятный фронтенд на JavaScript с пятью разделами: Главная, Теория, Практика, Тестирование и Результаты.

## Ценность и принципы

- **Обучение основам ООП.** Теория, примеры, задания, проверка знаний и взаимная проверка по критериям будут добавляться постепенно. Сейчас будущие учебные функции обозначены заглушками.
- **Понятность.** Создаваемые для проекта файлы README, Markdown, TRACE и SKILL пишутся на русском языке, чтобы владелец и одногруппники могли их прочитать и понять.
- **Небольшой масштаб.** Проект не создаётся для продаж или крупного публичного развертывания.

## Границы курса и проекта

Текущий каркас включает локальный запуск, навигацию и адаптивный интерфейс. Подробные результаты обучения, структура курса и его точный тематический объём остаются для отдельного обсуждения. Они не выводятся из названий имеющихся лекций и лабораторных; исходные PDF сохраняются.

React/Vite и обычный CSS служат небольшим учебным фронтендом. Текущий этап не включает сервер, базу данных, аккаунты, действующие задания и тесты, оценки и сохранение прогресса. Публикация и коммерческие функции не планируются. Будущую взаимную проверку и обмен результатами сначала рассматриваем локально, например файлами, отдельным решением.
