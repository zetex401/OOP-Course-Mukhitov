# North Star проекта OOP-Course-Mukhitov

## Назначение

Проект планируется как простой веб-сайт на Python, который поможет владельцу и его одногруппникам освоить основы объектно-ориентированного программирования. В проект входит проверочный тест для владельца и одногруппников.

## Ценность и принципы

- **Обучение основам ООП.** Проект служит для изучения, а тест помогает владельцу и одногруппникам проверить свои знания.
- **Понятность.** Создаваемые для проекта файлы README, Markdown, TRACE и SKILL пишутся на русском языке, чтобы владелец и одногруппники могли их прочитать и понять.
- **Небольшой масштаб.** Проект не создаётся для продаж или крупного публичного развертывания.

## Границы курса и проекта

Подтверждённые границы сейчас ограничиваются обучением основам ООП для владельца и его одногруппников и проверкой знаний тестом. Подробные результаты обучения, структура курса и его точный тематический объём владелец оставил для отдельного обсуждения. Они не выводятся из названий имеющихся лекций и лабораторных.

Не определены: состав и последовательность уроков, механика теста, оценивание и хранение результатов, учётные записи, технический стек Python и способ развёртывания. Эти решения не входят в текущую конфигурацию TFW.
