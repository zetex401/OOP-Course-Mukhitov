## Основы · 8 баллов

Один верный ответ — один балл.

### Что означает SRP?

1. Ровно один метод в классе
2. Одна причина изменения, связанная с обязанностью класса
3. Запрет вызова других объектов

### У тарифного сервиса высокая cohesion, если…

1. Его методы посвящены тарифным правилам
2. Он управляет также экраном и SQL
3. У него вообще нет зависимостей

### Где выбирают новый способ оплаты при расширении по OCP?

1. В новой ветке if внутри process_tap
2. В каждом тесте старого способа
3. В точке сборки, передавая новую стратегию терминалу

### Сигнатуры методов одинаковы. Достаточно ли этого для LSP?

1. Нет, нужно сохранить смысл контракта и обещания клиенту
2. Да, Python гарантирует поведение
3. Да, если имя класса содержит Strategy

### Какой контракт нужен клиенту, который только проверяет право проезда?

1. Все операции платной карты и сканера
2. Только is_valid()
3. Обязательные charge() и print_receipt()

### Как терминал зависит от репозитория по DIP?

1. Создаёт SQLiteRepository внутри process_tap
2. Хранит SQL строку в методе
3. Принимает контракт record_success(card_id, amount)

### Что является внедрением зависимости через конструктор?

1. self.repo = InMemoryRepository() внутри терминала
2. TransitTerminal(..., repository=repo, ...)
3. Вызов глобального контейнера из process_tap

### Что гарантирует аннотация Protocol при обычном запуске Python?

1. Она не проверяет смысл поведения автоматически
2. Автоматически откатывает оплату
3. Автоматически проверяет все предусловия

## Случай 1 · Новый способ оплаты · 3 балла

Терминал получает payment извне и вызывает process(Decimal("100.00")). True — оплата принята, False — отклонена. Для любой допустимой суммы ожидается bool.

### Нужно добавить Bluetooth. Какое изменение сохраняет выбранную точку расширения?

1. Добавить if mode == bluetooth внутрь терминала
2. Написать BluetoothPayment.process и передать экземпляр в терминал
3. Скопировать весь терминал в BluetoothTerminal

### Новая стратегия возвращает строку "False" при отказе. Что увидит if not payment.process(amount)?

1. Отказ, потому что написано False
2. Ошибка типов до вызова
3. Непустая строка истинна: терминал ошибочно продолжит успех

### Как подтвердить совместимость нового способа с терминалом?

1. Прогнать общий сценарий успеха и отказа через тот же TransitTerminal
2. Проверить только имя класса
3. Проверить только отсутствие синтаксических ошибок
