## 9. Найдите две проблемы

```python
class Card:
    def __init__(self):
        self.balance = 50

    def pay(self, fare):
        self.balance -= fare
        if self.balance < 0:
            raise ValueError("Не хватает денег")
```

Почему этот класс не защищает баланс? Укажите проблему интерфейса и проблему порядка действий. Предложите исправление словами.

## 10. Проследите изменения

