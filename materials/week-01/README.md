## Готовность: проверка, а не обещание установки

Нужны базовые переменные, if, функции, списки/словари, импорты и работа в терминале. В первые 5 минут теории:

1. Выполните `python --version`: нужен 3.12+. На Windows при необходимости используйте `py -3.12` вместо python.
2. Выполните `python -m pytest --version` в выбранной среде.
3. Напишите функцию, которая отвергает отрицательное число через ValueError; покажите, что `b = a; b.clear()` очищает исходный список a.

Если команды или действие не получились, среда/предпосылки не подтверждены. Запишите конкретную ошибку и обратитесь к организатору; установка/повторение могут потребовать дополнительного времени, это gap полного маршрута, а не тайно добавленные обязательные минуты. Выполнение README не свидетельствует о готовности всей группы.

Команды подготовки при отсутствии среды (не обещание уложиться в 5 минут): установить публичный Python 3.12+, затем в терминале:

```powershell
python -m venv .venv-week1
.\.venv-week1\Scripts\python.exe -m pip install pytest
.\.venv-week1\Scripts\python.exe -m pytest --version
```

На macOS/Linux используйте `.venv-week1/bin/python`. Далее «python» означает выбранный интерпретатор этой среды, например полный путь к нему. Официальная загрузка: [Python](https://www.python.org/downloads/).

## Что дано и что делаете вы

[starter.py](examples/starter.py) создаёт стандартную папку domain с сигнатурами, импортами Decimal/UTC/UUID и пятью готовыми проверками: _text, _decimal, _money, _count, _aware_time. Они уже проверяют значения — это предоставленная помощь, а не самостоятельно написанные вами правила.

Вы реализуете публичный интерфейс и все переходы/отказы четырёх сущностей, правильно применяете проверки, защищаете коллекцию, пишете свои пять сценариев и дополнительные наблюдения, запускаете/исправляете их, объясняете результат в README и защите. Каркас намеренно вызывает NotImplementedError в незавершённых методах; в сдаваемой модели такой логики не остаётся.

Полный [эталон](examples/reference_solution.py) и [справочные проверки](examples/test_reference.py) доступны отдельно после своей попытки. Их авторство не становится вашим при копировании. Онлайн-балл 0–20 измеряет выбранные ответы; лабораторная оценивается отдельно вручную 5+7+5+3=20, суммы не складываются.
