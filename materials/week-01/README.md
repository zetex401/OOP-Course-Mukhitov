# Неделя 1. От словарей к объектам: инкапсуляция и инварианты

Готовый учебный комплект для нашей группы. Учебный язык - **Python 3.12+**; JavaScript/React относятся к самому сайту, а не заменяют язык заданий из PDF.

К концу недели вы сможете объяснить класс и экземпляр, выделить состояние/поведение, сформулировать инварианты и реализовать небольшую модель Avtobys, которая отклоняет недопустимые операции без повреждения состояния.

## Что нужно знать заранее

Переменные, `if`, функции, списки/словари и вызов функций в Python. Проверьте себя: сможете написать функцию, которая отвергает отрицательное число, и объяснить, почему `items.append(...)` меняет список? Если нет, повторите эти конструкции до лабораторной.

## Как запустить примеры

Из корня проекта, в терминале с установленным Python 3.12+:

```powershell
python materials/week-01/examples/reference_solution.py
python -m venv .venv-week1
.\.venv-week1\Scripts\python.exe -m pip install pytest
.\.venv-week1\Scripts\python.exe -m pytest materials/week-01/examples/test_reference.py -q
```

На macOS/Linux вместо `.\.venv-week1\Scripts\python.exe` используйте `.venv-week1/bin/python`. Если Windows использует команду `py -3.12`, замените ею первые два вызова `python`. Виртуальная среда нужна только для учебных Python-тестов; Node-зависимости сайта не меняются. Локальную `.venv-week1` не включайте в сдаваемые файлы.

Эталон собран в один файл, чтобы его было удобно изучить. Собственную лабораторную оформите по структуре в [задании](practice.md). Для знакомства с материалами запускать Python необязательно: весь текст и код доступны в файлах.

## Основа и границы недели

Из набора из девяти лекций и девяти лабораторных выбрана первая пара: она прямо посвящена первой неделе. Названия/вводные части остальных документов просмотрены для понимания последовательности курса: далее идут отношения объектов, полиморфизм, SOLID, паттерны и архитектура. Эти темы здесь не забегают вперёд.

Основные источники преподавателя Санжара Аубакирова, курс CS2203, КазНУ:

- [Лекция 1. От процедурного подхода к объектам. Инкапсуляция](../../.tfw/COURSE-MATERIALS/01_Лекция_01_От_процедурного_подхода_к_объектам_Инкапсуляция.pdf): с. 1-3 - контекст, объект и инварианты; с. 4-6 - карта, свойства, исключения и богатая модель; с. 6-7 - контрольные вопросы.
- [Лабораторная 1. Моделирование домена Avtobys](../../.tfw/COURSE-MATERIALS/02_Лабораторная_01_Моделирование_домена_Avtobys_Защита_инвариантов.pdf): с. 1 - среда и структура; с. 2 - Bus/Route и баллы; с. 3 - карта/билет, обязательные тесты и защита.

Это авторская адаптация для самостоятельного обучения, а не дословная копия и не официальное изменение требований преподавателя. Сохранены четыре сущности, пять обязательных сценариев pytest и схема оценки 5 + 7 + 5 + 3 = 20. Публикация в GitHub, указанная в исходной лабораторной, для нашей локальной учебной версии не требуется; требования официальной сдачи проверяйте по исходному PDF/у преподавателя.

Уточнения этой адаптации: общий метод оплаты `pay()` вместо лекционного `charge_fare()`; явная граница срока билета; контролируемое время в тестах; конечные Decimal-суммы; округление итогового платежа; нормализация строк и отказ от `bool` вместо числа пассажиров. Подробности отмечены в задании. Оценки, тест и рубрика используются вручную; автоматическое оценивание на сайте или хранение прогресса этим комплектом не реализуются.
